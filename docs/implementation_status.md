# 实施状态

## 已完成

- 固定工作区参数、观察位、三分类料盒配置。
- RGB-D 观察数据和高度图转换接口。
- VPG 推/抓统一动作契约与无权重安全启发式基线。
- Piper 安全适配层：工作区边界、推动长度、最低/最高高度、连续失败停止。
- `SimPiperBackend` 软件闭环和 3 个单元测试。
- YOLOv8-seg 可选分类器和像素位置类别查询。
- ROS Noetic 包、launch、Ubuntu 环境准备脚本。

## 现场实施前必须完成

- 用官方 `piper_ros` 驱动确认实际末端控制消息、夹爪接口和状态消息。
- 填写相机到 Piper 基座的手眼标定，而不是使用默认相机坐标映射。
- 使用真实连接器采集并标注数据，训练并放入 `weights/connector_seg.pt`。
- 将已验证的 ROS 消息映射写入 `piper_ros_backend.py`，再执行单次低速动作测试。
- 完成急停、碰撞、IK 无解和动作超时测试后，才允许 `use_sim:=false`。
