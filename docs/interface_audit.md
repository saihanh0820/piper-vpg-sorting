# 真实设备接口审计表

在切换 `use_sim:=false` 前必须逐项填写并由现场程序验证。空白项表示尚未具备真机运行条件。

| 项目 | 现场确认内容 |
|---|---|
| CAN 所有者 | 仅官方 `piper_ros` 节点连接 `can0` |
| 末端目标接口 | Topic/Service 名称、消息类型、坐标单位 |
| 姿态接口 | 固定向下姿态表示、弧度/角度约定 |
| 夹爪接口 | 开合命令、力/速度单位、完成反馈 |
| 完成状态 | `/arm_status` 实际消息类型和正常状态值 |
| 故障状态 | IK 无解、关节超限、碰撞、急停的字段和值 |
| 坐标变换 | 相机到基座的 TF 或手眼标定矩阵 |
| 观察位 | 实测安全位姿和稳定等待时间 |
| 工作区 | 盘面四边、最低末端高度和最大推动端点 |
| 料盒 | A/B/C 基座坐标、释放高度和避障路径 |

## 现场联调顺序

1. 运行官方驱动并确认 CAN 只有一个连接者。
2. 用已有单次抓取程序完成一个单物体抓取。
3. 手动调用观察位、夹爪、末端移动和状态读取。
4. 将已确认接口封装进 `piper_ros_backend.py`，补充对应消息依赖。
5. 低速执行 `single_action_test.py`，验证越界、超时和急停。
6. 最后才连接 VPG 和 YOLO 状态机。
